# 🧠 Quiz Brain

### A Simple Interactive True/False Quiz Application Built with Python

## 📌 Overview

Quiz Brain is a beginner-friendly Python quiz application that allows users
to answer a series of True/False questions through the terminal.

The project demonstrates how Python classes, objects, methods, lists,
loops, conditional statements, and user input can be combined to build
a simple interactive application.

The quiz displays each question, accepts the user's answer, checks it
against the correct answer, and continues until all questions have been
answered.

---

## 🎯 Project Goal

The main goal of this project is to build a simple quiz system while
practicing Python Object-Oriented Programming (OOP) and understanding
how multiple Python modules can work together.
---

## ✨ Features

- 📚 Stores quiz questions and answers
- ❓ Displays questions one at a time
- ⌨️ Accepts True/False answers from the user
- ✅ Checks whether the user's answer is correct
- ❌ Displays the correct answer when the user is wrong
- 🔄 Automatically moves to the next question
- 🧠 Uses a QuizBrain class to manage quiz logic
- 🛑 Stops when there are no questions remaining
